# Licensing the data

The `LICENSE` file (MIT) covers the **code**. This file covers everything else,
because a dataset and a program are not the same kind of thing.

## The structural mapping — MIT, and probably not ownable anyway

The correspondence between the 256 Odù and the 256 byte values is a
mathematical fact about a traditional system. It is not an invention of this
project and it is not plausibly anyone's property. MIT is applied so nobody has
to wonder, but the honest position is that facts are not copyrightable.

## The compilation — CC BY-SA 4.0

The selection, arrangement, verification records, citations and orthographic
work represent effort that *is* protectable in some jurisdictions as a database
right. Those are offered under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

Share-alike is deliberate. A corrected, sourced dataset is worth more to
everyone if corrections flow back.

## What this project does **not** license

**Ẹsẹ Ifá — the verses.** None are reproduced here. What the corpus holds are
page references and pointers. Those citations are ours to license; the verses
they point at are not.

**Material from cited sources.** Bascom (1969), Abimbola, and the recordings
cited remain under their own rights. Nothing here grants any permission over
them, and a page reference is not a licence to reproduce the page.

## If you are a practitioner

If anything here misrepresents the tradition, that is a defect regardless of
what any licence permits, and correcting it takes priority over the terms
above. Open an issue or get in touch.
