# Code of Conduct

This project holds material from a living religious tradition. That shapes what
good conduct means here, so this document says it plainly rather than deferring
entirely to a template.

## The standard

Be decent to each other. Assume the person on the other side is acting in good
faith and knows something you don't. Harassment, personal attacks, demeaning
comments, and unwelcome attention are not tolerated, in issues, pull requests,
commits, or anywhere else this project is discussed.

## What this project asks beyond that

**Ifá is practised.** It is not a dead system to be mined, and the people who
know it best are usually not the people most comfortable opening a GitHub
issue. Treat practitioners and Yorùbá speakers as authorities on the material,
not as sources to be fact-checked against a book.

**Disagree about sources, not about people.** A correction that says "Bascom
records this differently, here is the page" is exactly what this repo is for. A
correction that says "you clearly don't understand Ifá" is not — say what is
wrong and how you know.

**Do not use the issue tracker for divination or religious dispute.** Questions
about what an Odù *means* in practice belong with a practitioner. Questions
about whether the dataset *records* it correctly belong here.

**Orthography is not a detail.** Tonal marks and subdots carry meaning. Do not
strip them for convenience, and do not treat someone's insistence on them as
pedantry.

## Scope and enforcement

This applies in all project spaces and when representing the project publicly.

Report conduct issues by opening an issue, or privately to the maintainer via
the contact in [`CITATION.cff`](CITATION.cff). Reports are handled discreetly.
Maintainers may edit, hide, or delete contributions that violate this document,
and may block persistent offenders.

Maintainers who do not follow this themselves should be called out, publicly if
necessary.
