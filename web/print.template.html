Print a fingerprint

Any file becomes four figures — the same short, spoken/readable fingerprint the CLI prints, laid out as something you can actually print or engrave.

This is a keepsake, not a security check. A four-figure fingerprint is 24 bits — enough to catch an accident (the wrong file, a truncated copy), not enough to prove authenticity to anyone motivated to fake it. Made for a memento, not a signature.

Downloaded SVG renders correctly in a browser or Inkscape. Some laser-engraving software reads the figures (real SVG shapes) but not the caption text (embedded as HTML) — if a tool balks, print to PDF instead and use that.
Hashing happens in your browser (Web Crypto SHA-256) — the file never leaves your machine. Figures are drawn server-side at build time from the canonical data, same as everywhere else in odu-core.
